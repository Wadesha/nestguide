## 产品简介

**初生宝典**是一款专为**零基础新手父母**设计的孕晚期到新生儿期引导工具。

如果你是这样的用户：

- 孕晚期（28周+），对即将到来的生产感到焦虑
- 完全不知道要准备什么、什么时候该做什么
- 网上信息太多太杂，不知道信谁的
- 产后手忙脚乱，记不住喂奶/换尿布/睡觉的时间

**初生宝典就是为你设计的。**

---

## 核心功能

### 产前准备
- 按孕周自动生成任务清单
- 待产包 checklist（妈妈篇+宝宝篇+证件篇，带图说明）
- 产检提醒 + 自动倒计时
- 数宫缩计时器 + 入院决策助手
- 破水/见红/宫缩鉴别指南

### 分娩指南
- 产程分阶段引导（第一到第三产程）
- 呼吸法动画/音频引导
- 陪产人配合指南
- 剖腹产完整流程

### 产后恢复（妈妈）
- 按天推送恢复要点
- 伤口护理步骤图解
- 恶露追踪 + 异常预警
- 心理状态自评（EPDS量表）
- 产后运动推荐

### 新生儿护理（宝宝）
- 喂养/换尿布/睡眠一键记录
- 自动生成规律图表
- 黄疸监测 + 复查提醒
- 洗澡/抚触/拍嗝步骤图解
- 肠绞痛缓解方法

### 疫苗接种
- 自动生成接种时间表
- 提前3天/1天推送提醒
- 接种后反应记录指南

### 每日首页
- "今天该做什么"卡片式展示
- 按优先级排序，做完即安心

## 产品理念

```
新手不懂 → 打开 App → 告诉我今天要做什么 → 一步步做完 → 安心入睡
```

**三个原则：**

1. **零学习成本** — 打开 App 就是"今日待办"，不需要任何教程
2. **按阶段解锁** — 不一次性展示所有功能，只给当前需要的
3. **有温度的设计** — 每个任务都配有"为什么做"和"怎么做"，不是冷冰冰的清单
